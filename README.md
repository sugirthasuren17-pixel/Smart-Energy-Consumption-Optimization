# Smart Energy Consumption and Optimization

## Overview
This project analyzes energy consumption patterns across appliances and building types using Python and data visualization techniques. It also compares energy consumption with renewable energy generation to identify potential opportunities for optimization.

## Objectives
- Analyze energy consumption by appliance.
- Compare energy usage across building types.
- Identify hourly consumption patterns.
- Compare energy consumption and renewable generation.
- Recommend practical energy-saving strategies based on the analysis.

## Dataset
The dataset includes:
- Timestamp
- Building type
- Appliance
- Energy consumption (kWh)
- Temperature (°C)
- Occupancy percentage
- Tariff period
- Renewable generation (kWh)
- Reading ID

**Data note:** The dataset is synthetic sample data created for educational and demonstration purposes. It does not represent actual building meter readings.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

## Workflow
1. Load the cleaned dataset.
2. Inspect dataset structure and quality.
3. Analyze consumption by appliance and building.
4. Study hourly energy consumption.
5. Compare consumption with renewable generation.
6. Create visualizations and generate optimization recommendations.

## Expected Outcome
The analysis helps illustrate energy usage patterns and identify areas where energy-saving strategies may be considered.
